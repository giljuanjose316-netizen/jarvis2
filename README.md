# Jarvis 2

Asistente personal por voz construido desde cero.

## Estructura inicial

- `index.html` — interfaz principal.
- `style.css` — estilos de la interfaz.
- `script.js` — lógica inicial de reconocimiento de voz.
- `assets/` — recursos del proyecto que añadiremos posteriormente.

## Estado actual

Base inicial creada. El siguiente objetivo es conectar y probar el flujo de micrófono y, después, añadir respuesta por voz y comandos de Jarvis.
